# Getting Started

This section takes you from *nothing installed* to *running your first
experiment*, with no guesswork.

1. **[Installation](installation.md)** — get the software onto your machine
   using `uv` or Docker. **Nothing is installed system-wide.**
2. **[First Steps](first-steps.md)** — launch the app, create your configuration,
   and run a simulated measurement.

When you are comfortable with the basics, continue with the hands-on
**[Tutorials](../tutorials/index.md)**, which teach the software through small,
self-contained experiments you can run *without any hardware*.

!!! info "What you need"
    - A computer running **Windows, macOS or Linux**.
    - About **15 minutes**.
    - **No laboratory hardware** — everything in Getting Started and the
      Tutorials runs in a built-in *debug mode* that simulates instruments.
